# Veyra UI Design

The frontend should present Veyra as a modern enterprise AI product:
- glassmorphism surfaces with backdrop blur
- dark, premium visual hierarchy
- responsive layout
- strong typography and generous spacing
- consistent Veyra branding
- chat-first knowledge experience
- source/citation visibility
- dashboard-ready component system

The starter stylesheet is in `frontend/src/veyra-glass.css`.
